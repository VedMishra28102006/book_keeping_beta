(a) A book keeping application with:

  (i) Authentication system

  (ii) Financial year management

  (iii) User management

  (iv) Journalizing and automatic ledger posting

  (v) Trial balance and balance sheet preparation

  (vi) Export of books in CSV format

  (vii) Cookie-less support

(b) How to Run:

  (i) Set the ADMIN_USERNAME and ADMIN_PASSWORD environment variables.

  (ii) Download python-3.13.

  (iii) Navigate to the project's root directory on terminal or command prompt.

  (iv) Run "pip install requirements.txt" command.

  (v) Run "python3.13 server.py" command.

  (vi) Open http://localhost:10000/ on the web browser.

  (vii) Press CTRL+C to close the server when the work is done.
